# LUNA
A Programing Agent "𝑳𝑼𝑵𝑨", made by Team.𝓛𝓾𝓷𝓪𝓻𝓮𝓩.<br>
这是一个**上下文感知的多Agent协作代码生成框架**！它可以为你做架构、写代码、作测试...

---

## 快速开始

### 环境要求
- Python 3.14+
- Node.js 18+

### 安装
```bash
git clone https://github.com/Imaxiea/LUNA.git
cd LUNA
pip install -r requirements.txt
```

### 运行
```bash
python main.py
```
